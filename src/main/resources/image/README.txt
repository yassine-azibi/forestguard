DOSSIER IMAGES - ForestGuard
=============================

Ce dossier doit contenir 2 images :

1. forest-logo.png
   - Format : PNG avec transparence
   - Taille : 128x128px ou 256x256px
   - Contenu : Logo ForestGuard (arbre, feuille, symbole forestier)

2. foret-back.jpg
   - Format : JPG
   - Taille : 1920x1080px (Full HD)
   - Contenu : Photo de forêt (tons verts, luminosité moyenne)

IMPORTANT :
-----------
Si ces images ne sont pas présentes, l'application utilisera :
- Un emoji 🌲 comme logo temporaire (déjà configuré)
- Un fond de couleur au lieu du background

L'application fonctionnera normalement, mais l'aspect visuel sera moins professionnel.

OÙ TÉLÉCHARGER LES IMAGES :
----------------------------
Consultez le fichier INSTRUCTIONS_IMAGES.md à la racine du projet pour :
- Sites de téléchargement gratuits (Unsplash, Pexels, Flaticon)
- Spécifications détaillées
- Instructions de redimensionnement

POUR TESTER RAPIDEMENT :
------------------------
Vous pouvez créer des images temporaires ou utiliser l'application
avec l'emoji 🌲 qui est déjà configuré dans toutes les interfaces.
