1. main = Code stable en production - INTERDIT de pusher directement
2. dev = Branche d'intégration - INTERDIT de pusher directement - Seulement via Pull Request

FORMAT DES BRANCHES FEATURE (OBLIGATOIRE):
Format: feature/nom-en-minuscules-avec-tirets

**WORKFLOW COMPLET ÉTAPE PAR ÉTAPE:**

ÉTAPE 1 - CLONAGE:
Dans IntelliJ: File → New → Project from Version Control → URL: https://github.com/yassine-azibi/forestguard.git → Clone
Attendre que Maven télécharge les dépendances

ÉTAPE 2 - VÉRIFICATION:
Vérifier JDK 17: File → Project Structure → Project SDK → Java 17
Rebuild: Build → Rebuild Project (Ctrl+Shift+F9)
Vérifier aucune erreur de compilation

ÉTAPE 3 - CRÉATION BRANCHE FEATURE (CRITIQUE):
Git → Branches... → Sélectionner "dev" → New Branch → Nom: feature/mon-module → Cocher "Checkout branch" → Create
Vérifier en bas à droite: doit afficher "feature/mon-module"

ÉTAPE 4 - DÉVELOPPEMENT:
Développe ton module avec ta propre structure de code
Utilise ta propre base de données locale pour les tests
Le chef de projet intégrera tout lors du merge

ÉTAPE 5 - TESTS:
Build → Rebuild Project (Ctrl+Shift+F9)
Tester toutes les fonctionnalités de ton module

ÉTAPE 6 - COMMIT:
Git → Commit (Ctrl+K)
Sélectionner tes fichiers (PAS .idea/, PAS target/)
Message: "✨ Description claire de ce que tu as fait"
Commit (PAS "Commit and Push")

ÉTAPE 7 - VÉRIFICATION AVANT PUSH:
Vérifier en bas à droite: "feature/mon-module" (PAS "dev")
Vérifier qu'aucun fichier .idea/ ou target/ n'est commité

ÉTAPE 8 - PUSH:
Git → Push (Ctrl+Shift+K)
Vérifier: feature/mon-module → origin/feature/mon-module
Push

ÉTAPE 9 - PULL REQUEST:
Navigateur → https://github.com/yassine-azibi/forestguard
Cliquer "Compare & pull request"
Vérifier: Base: dev ← Compare: feature/mon-module
Titre: "✨ Module [nom]"
Description: Liste des fonctionnalités ajoutées
Assigner Yassine Azibi comme reviewer
Create pull request

ÉTAPE 10 - ATTENDRE REVIEW:
Ne PAS merger soi-même
Attendre validation du chef de projet
Si modifications demandées: modifier sur feature/mon-module, commit, push

**COMMANDES GIT (ALTERNATIVE LIGNE DE COMMANDE):**
Étape 1 - Cloner: git clone https://github.com/yassine-azibi/forestguard.git
Étape 2 - Vérifier branche actuelle: git branch (doit afficher "dev")
Étape 3 - Créer MA branche: git checkout -b feature/mon-module
Étape 4 - Vérifier que je suis sur MA branche: git branch (doit afficher "* feature/mon-module")
Étape 5 - Travailler sur mon code
Étape 6 - Commit: git add . puis git commit -m "✨ Description"
Étape 7 - Push MA branche: git push origin feature/mon-module
Étape 8 - Créer Pull Request sur GitHub: feature/mon-module → dev

✅ Ma Pull Request va de feature/mon-module vers dev, PAS vers main
✅ Le code compile sans erreurs
✅ Pas de fichiers .idea/ ou target/ dans le commit
✅ Tu peux pusher les clés API (sécurité désactivée temporairement)
