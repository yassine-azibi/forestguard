DOSSIER VIDÉOS - Visites virtuelles 360° des forêts
====================================================

Ce dossier doit contenir les vidéos 360° des forêts tunisiennes pour les visites virtuelles.

FICHIERS SUGGÉRÉS:
├── foret1.mp4  (Vue panoramique)
├── foret2.mp4  (Canopée)
├── foret3.mp4  (Sous-bois)
├── foret4.mp4  (Rivière forestière)
├── foret5.mp4  (Faune sauvage)
└── foret6.mp4  (Coucher de soleil)

FORMAT:
- Format: MP4 (H.264)
- Résolution: 1920x1080 ou supérieure
- Type: Vidéo 360° ou vidéo panoramique

SOURCES:
1. Demander au camarade du module gestionforet s'il a des vidéos
2. Utiliser des vidéos de démonstration
3. Filmer des vidéos dans les forêts tunisiennes

IMPORTANCE:
Cette fonctionnalité est OPTIONNELLE.
Sans vidéos, le bouton "Visite Virtuelle" affichera un message d'erreur,
mais le reste de l'application fonctionnera normalement.

ALTERNATIVE:
Si pas de vidéos disponibles, vous pouvez désactiver le bouton "Visite Virtuelle"
dans le code de CarteController.java ou CarteForestGuard.html.
