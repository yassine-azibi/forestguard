DOSSIER LEAFLET - Bibliothèque de cartographie
================================================

Ce dossier doit contenir les fichiers de la bibliothèque Leaflet 1.9.4:

FICHIERS REQUIS:
├── leaflet.js          (bibliothèque JavaScript principale)
├── leaflet.css         (styles CSS)
└── images/             (dossier d'icônes)
    ├── marker-icon.png
    ├── marker-icon-2x.png
    └── marker-shadow.png

TÉLÉCHARGEMENT:
1. Aller sur: https://leafletjs.com/download.html
2. Télécharger: Leaflet 1.9.4 (leaflet.zip)
3. Extraire les fichiers dans ce dossier

OU

Demander au camarade du module gestionforet de partager son dossier Leaflet complet.

IMPORTANCE:
Sans ces fichiers, la carte fonctionnera uniquement avec une connexion internet
(chargement depuis les CDN externes).

Avec ces fichiers, la carte fonctionnera en mode local (serveur proxy Java).
